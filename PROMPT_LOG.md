# Prompt & Engineering Log

A record of the prompts used to build RedactLocal, the tool that ran each one, and what changed as a result. The full text of every prompt is in [PROMPTS.md](PROMPTS.md).

## How this was built

1. The hackathon brief was turned into a **meta-prompt** (drafted with an AI assistant).
2. **Gemini** expanded the meta-prompt into a detailed master prompt.
3. **Google Antigravity** built the code from that prompt and ran its own checks (Node scripts, self-tests).
4. A second meta-prompt to Gemini produced a **multi-page redesign prompt**, followed by six refinement prompts covering UI, detection, performance, visual polish, accessibility and documentation.
5. The site is deployed from GitHub to **Vercel** as a static site.

Git tags: `v1-working` (single-page version) and `v2-ui` (multi-page redesign).

## Verification

Anyone can reproduce the main claims:

- **Self-tests:** open `how-it-works.html` and read the `Self-test: N/N passed` badge, or run `window.runSelfTests()` in the browser console.
- **No network requests:** open DevTools, go to the Network tab, clear it, load the sample on the Sanitizer page and download the output. The request list should stay empty.
- **Offline use:** disconnect from the internet and reload; every page and feature should still work.
- **Luhn false-positive handling:** load the sample text and check that the Luhn-rejected counter is above zero while the invalid 16-digit numbers are not highlighted as cards.

Test counts and timings in this log were reported by the build agent during its runs; re-run the checks above to confirm them on your own machine.

## Challenges and fixes

- **Single page to multi-page without regressions:** the detection engine was extracted into `engine.js` unchanged and guarded by the self-test suite, so the redesign could not silently alter detection.
- **Static-host safety:** file names, relative links, script tags and favicons were checked so the same files work from `file://` and on a case-sensitive host.
- **Stats double-counting:** copying and then downloading the same text counted twice; fixed by fingerprinting only the raw input, in memory, never stored.
- **Tooltip clipping:** native `title` tooltips clipped inside scrollable panes; replaced with a viewport-clamped custom tooltip.
- **Contrast failures:** several highlight and status colours failed WCAG AA in one theme and were adjusted.
