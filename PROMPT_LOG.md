# Prompt & Engineering Log

**How this was built:** The hackathon brief was turned into a meta-prompt, Gemini expanded it into a master prompt, Google Antigravity built and verified the code across iterative audits, and the static site was deployed on Vercel. Full verbatim prompts for every stage are recorded in [PROMPTS.md](PROMPTS.md).
