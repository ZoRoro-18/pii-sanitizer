Privacy & Security Architecture

Built from the ground up with zero external calls, strict DOM escaping, and verifiable offline execution.

Try Sanitizer

100% In-Browser Execution

Every regex scan, Luhn/Verhoeff checksum, CSV parse, and redaction runs strictly inside your browser's JavaScript VM. Files read via FileReader never leave local RAM.

Zero Third-Party Assets

No Google Fonts, no icon CDNs, no npm bundles, no analytics, and zero calls to fetch or XMLHttpRequest. All icons are inline SVGs and typography uses system stacks.

Strict XSS Protection

All user-supplied text is passed through escapeHtml() (escaping &, <, >, ", and ') before injecting diff highlights or tooltips into the DOM.

Count-Only Local Storage

localStorage stores only redactlocal_theme (light/dark) and redactlocal_stats_v1 (aggregate numeric counts). User text, output, filenames, and pseudonym maps are never persisted.

Verify It Yourself in 60 Seconds

Follow these reproducible steps to confirm zero data exfiltration in your own browser.

1

Open Browser DevTools

Press F12 (or Cmd+Option+I on macOS) and switch to the Network tab.

2

Clear & Sanitize Data

Click Clear in the Network log, open Sanitizer, load the sample text or upload a .csv file, and download the output.

3

Confirm 0 Network Requests

Inspect the Network panel: confirm 0 outbound requests were made during parsing, masking, copying, or downloading.

4

Disconnect Wi-Fi / Airplane Mode

Turn off your internet connection and navigate across all 5 pages—every detector, checksum explorer, and self-test continues working seamlessly.
